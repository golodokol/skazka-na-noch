# Сценарии и UX Telegram-бота

---

## 1. Команды BotFather

```
start - Начать и получить сказку
story - Быстрая сказка (последний режим)
profile - Профиль ребёнка
help - Как пользоваться
privacy - Политика данных
```

---

## 2. Flow: первый запуск

```mermaid
flowchart TD
    A[/start] --> B{Профиль есть?}
    B -->|Нет| C[Приветствие co-pilot]
    C --> D[Имя ребёнка]
    D --> E[Возраст 2-7]
    E --> F[Герой? Пропустить]
    F --> G[Главное меню 3 кнопки]
    B -->|Да| G
    G --> H{Выбор режима}
    H --> I[Генерация]
    I --> J[Текст сказки]
    J --> K[Feedback + после сказки]
```

### Текст приветствия

```
Добрый вечер 🌙

Я помогаю мамам и папам с вечерними сказками для малышей от 2 до 7 лет —
когда хочется тепла, а сил придумывать уже мало.

За полминуты соберу историю про вашего ребёнка: с именем, любимым героем
и, если расскажете пару слов о дне, — про сегодняшний вечер.

«Нет сил» — коротко и мягко. «5 минут» — чуть подробнее.
«Сегодняшний день» — про события вечера.
«Быстрое спасение» — готовая сказка под ситуацию.
Всё заканчивается спокойно — чтобы малышу было легче уснуть.

Читаете вы. Я только подсказываю, что рассказать сегодня.

Выберите режим:
```

**Клавиатура (Reply или Inline):**

| Кнопка | callback / action |
|--------|-------------------|
| 😴 Нет сил | `mode:tired` |
| ⏱ 5 минут | `mode:medium` |
| ✏️ Сегодняшний день | `mode:today` |
| 🆘 Быстрое спасение | `rescue:menu` → 12 сценариев |
| ⚙️ Профиль | `profile` |

## 3. Flow: «Сегодняшний день»

1. Бот: «Одной фразой — что было у {имя} сегодня? (можно голосовое)»
2. Пользователь: текст или voice → STT (P1)
3. Бот: «Читаю…» (typing action)
4. Генерация с учётом `day_context` + режима по умолчанию `tired`
5. Выдача сказки

---

## 4. Flow: генерация и ошибки

| Состояние | UX |
|-----------|-----|
| Старт | `sendChatAction(typing)` каждые 4 сек |
| Успех | Текст частями если >4096 символов |
| Timeout LLM | «Не успели за 30 сек — вот короткая запасная» (cached template) |
| Лимит free | «На этой неделе 5 сказок использованы. Завтра или подписка →» |
| Safety block | «Перепишу мягче» + 1 автоповтор |

---

## 5. Flow: после сказки

```
Как прошло?

[ 😴 Уснул ]  [ 🔄 Ещё одну ]
[ ⏳ Длинно ]  [ 😟 Не подошло ]
```

При `Длинно` → следующая генерация −20% слов.  
При `Не подошло` → уточнение: `Страшно` | `Скучно` | `Другое`.

**Блок «После сказки»** (всегда после текста):

```
💬 После сказки (по желанию):
1. Что помогло герою успокоиться?
2. Что хорошего было у тебя сегодня?

🤗 Можно завершить объятием и «Спокойной ночи, {имя}».
```

## 7. Flow: оплата (P1)

При исчерпании лимита:

```
На этой неделе бесплатные сказки закончились.

Подписка «Спокойные вечера» — 399 ₽/мес:
• безлимит сказок
• «сегодняшний день» каждый вечер
• аудио без экрана

[ Оформить ]  [ Позже ]
```

`Оформить` → Telegram invoice (Stars) или ссылка Prodamus.

---

## 8. Push (P1, opt-in)

- Запрос: «Напоминать в 20:30?» — только после 3 успешных сессий
- Текст: «{имя} уже спит? Если нет — сказка за 30 сек → /story»

## 9. Сообщения для BotFather

**Name:** Сказка на ночь  
**Description:** Вечерние сказки для малышей 2–7 лет — когда хочется тепла, а сил придумывать уже мало. За полминуты — с именем, героем и про сегодняшний день. Читаете вы, я подсказываю, что рассказать. (полный текст: `bot/texts.py` → `BOT_DESCRIPTION`)  
**About:** Не заменяем маму и папу. Снимаем нагрузку «что придумать» перед сном. 5 бесплатных сказок в неделю.
