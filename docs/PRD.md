# PRD: Сказка на ночь

**Версия:** 1.0 · **Дата:** июнь 2026 · **Владелец продукта:** TBD

---

## 1. Цели и не-цели

### 1.1 Цели MVP

1. Проверить гипотезу: родители **регулярно** используют бота в 20:00–22:00, если сказка приходит **< 60 сек** и **снимает когнитивную нагрузку**.
2. Достичь **D7 retention ≥ 25%** среди пилотной когорты (30–50 семей).
3. Валидировать WTP на персонализацию «сказка сегодняшнего дня» (конверсия в подписку ≥ 3%).
4. Обеспечить **безопасный** детский контент (0 инцидентов «страшно/неуместно» в пилоте).

### 1.2 Не-цели MVP

- Замена родителя полностью автономным аудио без его участия.
- Отдельное мобильное приложение.
- B2B / корпоративный benefit.
- Клонирование голоса родственников.
- Медицинские заявления («лечит бессонницу»).

## 3. Функциональные требования

### 3.1 Онбординг (≤ 2 минуты, можно пропустить)

1. Приветствие: позиционирование **co-pilot**, не замена.
2. Запрос: имя ребёнка, возраст (2–7), опционально любимый герой, «без страшного».
3. Кнопка **«Пропустить — сказка сейчас»** → дефолтный профиль, донастройка позже.

### 3.2 Главный экран (каждый вечер)

Три inline-кнопки:

- `Нет сил` → длина 2–3 мин, простой язык, минимум вопросов ребёнку
- `5 минут` → длина 4–6 мин, 1–2 вопроса после
- `Сказка вместо мультика` → текст + CTA аудио (P1)

Дополнительно: `Сегодняшний день` (текст/голос), `Ещё короче`, `Настройки`.

### 3.3 Генерация сказки

| Параметр | Требование |
|----------|------------|
| Latency | ≤ 30 сек (p50), ≤ 60 сек (p90) |
| Язык | Русский (MVP) |
| Структура | Завязка → мягкое развитие → **сонный финал** |
| Персонализация | Имя, возраст, герой, факт дня (если есть) |
| Запреты | Профиль «без страшного» + глобальный safety |

### 3.4 После сказки

- Кнопки feedback: `Уснул` · `Спросил ещё` · `Длинно` · `Страшно/не то`
- Блок **«После сказки»**: 2 вопроса + 1 фраза для близости (текстом)

### 3.5 Лимиты и монетизация

- Free: 5 генераций / календарная неделя
- При исчерпании: оффер подписки, не блокировать просмотр последней сказки

## 4. Нефункциональные требования

| Категория | Требование |
|-----------|------------|
| Доступность | 99% uptime в пилоте (допустимы плановые окна) |
| Приватность | Минимизация ПДн; не логировать полные тексты детей в открытые системы |
| Безопасность | Двухслойная модерация (prompt + post-filter) |
| Масштаб | До 500 DAU без смены архитектуры |
| Локализация | RU; архитектура готова к EN в v2 |

## 6. Критерии приёмки MVP

- [ ] Новый пользователь получает сказку по «Нет сил» < 60 сек после `/start`
- [ ] Профиль сохраняется между сессиями
- [ ] 5-я сказка за неделю показывает paywall
- [ ] Feedback влияет на длину следующей генерации
- [ ] 0 релизов с непройденным safety на тест-наборе из 50 промптов
- [ ] Пройден [LAUNCH_CHECKLIST.md](LAUNCH_CHECKLIST.md)
