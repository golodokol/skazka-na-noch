# Монетизация

---

## 1. Модель

**Freemium → подписка**, платный слой = **персонализация + безлимит + аудио**.

| Тариф | Цена | Включено |
|-------|------|----------|
| **Free** | 0 ₽ | 5 сказок / календарная неделя, профиль, 3 режима, feedback |
| **«Спокойные вечера»** | 399 ₽/мес (тест 299 / 499) | Безлимит, «сегодняшний день», аудио (P1), приоритетная генерация |
| **Разовый пакет** | 99–149 ₽ | 3 премиум-сказки (A/B WTP) |

**Не продавать на старте:** «библиотеку 1000 сказок» — слабая ценность по интервью.

---

## 2. Paywall UX

**Триггер:** 6-я генерация в неделю.

**Сообщение:**

```
На этой неделе 5 бесплатных сказок уже были 🌙

Подписка помогает нам делать персональные вечера каждый день:
• безлимит
• сказка из событий дня
• аудио — телефон экраном вниз

399 ₽/мес — меньше одной книги
```

Кнопки: `Оформить` · `Напомнить завтра` · `Почему платно?`

## 3. Платёжные каналы (РФ)

| Канал | Плюсы | Минусы |
|-------|-------|--------|
| **Telegram Stars** | Нативно в TG | Комиссия, восприятие цены |
| **Prodamus / ЮKassa** | Карты РФ, привычно | Вне TG flow |
| **СБП ссылка** | Быстро | Ручной учёт в MVP |

**Рекомендация MVP:** Stars для TG-native + Prodamus для тех, кто не хочет Stars.

## 4. Unit economics (цель)

| Метрика | Цель (6 мес) |
|---------|--------------|
| ARPU (paying) | 350 ₽/мес |
| Free → paid | 3–5% |
| Churn monthly | < 12% |
| CAC (органика TG) | < 150 ₽ |
| LTV/CAC | > 3 |

**При 500 paying × 399 ₽ ≈ 200k ₽ MRR** — ориентир устойчивости side-project.

## 6. Эксперименты WTP

| Тест | Варианты |
|------|----------|
| Цена | 299 vs 399 vs 499 ₽ |
| Paywall | После 3-й vs 5-й сказки |

| Фича | Paywall только на «сегодняшний день» |
