# Спецификация MVP

**Продукт:** Сказка на ночь · **Фаза:** MVP 0.1 · **Срок пилота:** 4–6 недель

---

## 1. Принцип MVP

Объединить три идеи из исследования в **один бот**:

1. **Сказка за 30 секунд** (P1)
2. **Антиусталость — 3 режима энергии** (P1 эмоционально)
3. **Библиотека быстрых спасений** (retention) — **P1 фазы**, 12 кнопок в неделе 3–4

**Первый экран = не анкета, а три кнопки.**

## 3. Режимы энергии (детально)

### 3.1 «Нет сил» (0/10)

| Параметр | Значение |
|----------|----------|
| Длина чтения | 2–3 мин (~300–450 слов) |
| Лексика | Простые предложения, тёплый тон |
| Сюжет | Минимум конфликта, плавный финал |
| Участие родителя | Текст «как будто говорит мама/папа» |
| После | 1 короткий вопрос или только фраза объятия |

### 3.2 «5 минут» (5/10)

| Параметр | Значение |
|----------|----------|
| Длина | 4–6 мин (~600–900 слов) |
| Сюжет | Лёгкая дуга: маленький герой → мягкое разрешение → сон |
| После | 2 вопроса + фраза близости |

### 3.3 «Сказка вместо мультика» — снято с меню MVP

Режим `screen_free` убран из бота (2026). Старые callback и `last_mode=screen_free` маппятся на «Нет сил».
Идея (аудио / «смотрим глазами») — в бэклоге, не в текущем UI.

## 4. Профиль ребёнка

```yaml
child_profile:
  name: string          # обязательно для персонализации
  age_years: int        # 2-7, влияет на лексику
  favorite_hero: string # опционально
  fears_block: bool     # "без страшного" default true
  interests: string[]   # v1.1
  last_story_feedback: enum
```

**Онбординг:** максимум 4 поля; всё опционально кроме имени для персонализированной ветки.

## 5. «Быстрые спасения» (P1) — ✅ в боте

Кнопка **🆘 Быстрое спасение** → 12 сценариев (`bot/rescue_scenarios.py`).  
Каждый — **template + LLM adapt** (возраст, имя, длина из режима tired/medium).

12 сценариев-кнопок:

1. Опаздываем ко сну  
2. Ребёнок перевозбуждён  
3. Двое детей — один сюжет  
4. Я засыпаю раньше ребёнка  
5. После ссоры / истерики  
6. После садика — много впечатлений  
7. Папа укладывает (другой тон)  
8. Бабушка укладывает  
9. Ребёнок требует «как вчера»  
10. Боится темноты (мягко, без P5-клиники)  
11. Не хочет спать вообще  
12. Скучает по маме/папе (командировка)

Каждый — **template + LLM adapt** (возраст, имя, длина из режима).

## 6. Технический минимум

См. [TECH_ARCHITECTURE.md](TECH_ARCHITECTURE.md).

**Стек MVP (рекомендация):**

- Python 3.11+ / Node 20+ (на выбор)
- `aiogram` 3.x или `python-telegram-bot`
- SQLite → PostgreSQL при >200 users
- Redis опционально для rate limit

## 7. Пилот

| Параметр | Значение |
|----------|----------|
| Размер | 30–50 семей |
| Набор | Личные контакты + 1–2 родительских TG-канала |
| Длительность | 4 недели |
| Сбор | Еженедельный опрос (3 вопроса) + метрики бота |

**Вопросы пилота:**

1. Использовали ли 3+ вечера за неделю?
2. Что было бы хуже без бота?
3. Заплатили бы 299 ₽/мес — да/нет/почему?
