# Чеклист запуска Telegram-бота

Использовать перед публичным релизом. Отмечать `[x]` по мере выполнения.

---

## A. BotFather и бренд

- [ ] Создан бот через [@BotFather](https://t.me/BotFather)
- [ ] Имя: **Сказка на ночь** (или доступный вариант)
- [ ] Username: `@...` (короткий, запоминающийся)
- [ ] Аватар 512×512 (тёплый, ночной, без пугающих образов)
- [ ] Description (до 512 символов) — co-pilot, 30 сек, 5 free/нед
- [ ] About — ссылка на privacy
- [ ] Команды: `start`, `story`, `profile`, `help`, `privacy`
- [ ] Menu Button → команда `/story` (опционально)

---

## B. Техника

- [ ] `.env` заполнен (см. `.env.example`)
- [ ] Webhook HTTPS или polling в dev
- [ ] БД миграции применены
- [ ] LLM API ключ с лимитом расходов
- [ ] Rate limit: 1 story / 30 sec / user
- [ ] Fallback templates загружены (10 шт.)
- [ ] Логирование без plaintext `day_context` в prod
- [ ] Бэкап БД настроен
- [ ] Мониторинг uptime (UptimeRobot / health endpoint)

---

## C. Продукт P0

- [ ] `/start` → 3 кнопки режима
- [ ] Онбординг профиля + пропуск
- [ ] Генерация < 60 сек (p90)
- [ ] Sleep-onset промпт активен
- [ ] Safety: 50 тестов пройдены
- [ ] Feedback после сказки
- [ ] Лимит 5/нед работает
- [ ] Тест-кейсы T1–T5 из BOT_FLOWS.md

---

## D. Контент и UX

- [ ] Тексты без «бот читает вместо вас»
- [ ] Блок «После сказки» на каждой истории
- [ ] Сообщение при ошибке LLM (fallback)
- [ ] Chunking для длинных сообщений (>4096)

---

## E. Юридическое

- [ ] Политика конфиденциальности опубликована
- [ ] Согласие при первом `/start`
- [ ] `/delete` или аналог
- [ ] Дисклеймер «не мед. помощь»
- [ ] Оферта для платежей (если P1 оплата в launch)

---

## F. Монетизация (P1, можно +1 неделя)

- [ ] Telegram Stars или Prodamus подключены
- [ ] Тестовый платёж 1 ₽ / тестовый invoice
- [ ] Подписка продлевается / отмена понятна пользователю
