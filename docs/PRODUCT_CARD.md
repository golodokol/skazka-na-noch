## 2. Проблема и инсайт

### Job to be done (ядро — P1)

**Когда** наступает вечер, ребёнок просит сказку, а у родителя нет сил думать, выбирать и читать выразительно,  
**хочу** быстро получить подходящую историю или сценарий ритуала,  
**чтобы** сохранить тёплый контакт, уложить ребёнка и не чувствовать себя плохим родителем.

### Главный инсайт (все источники)

| ❌ Не продаём | ✅ Продаём |
|-------------|-----------|
| Библиотеку сказок | **Снятие вечерней когнитивной нагрузки** |
| Замену родителя | **Co-pilot ритуала** — родитель остаётся «рядом» |
| «Уникальный ИИ-контент» | **Состояние**: спокойный ребёнок + вечер без вины |

### Цифры, подтверждающие масштаб

- **92%** работающих родителей — выгорание (Maven Clinic)
- **40%** считают чтение вслух «увлекательным» (было 64% в 2012)
- **60%** — вина за экранное время ребёнка
- **74%** готовы платить премиум за персонализацию с ребёнком в главной роли
- **~50%** детей 5–13 лет — протест укладывания (РФ)

---

## 3. Решение

**Telegram-бот**, который за **≤30–60 секунд** выдаёт персональную **сонную** сказку под ресурс родителя — для чтения вслух или спокойного аудио (телефон экраном вниз).

### Killer feature

**Вечерний ритуал за 30 секунд:** персональная сонная сказка под уровень энергии родителя — с именем ребёнка, событиями дня и любимым героем — которую родитель **читает сам** или включает **без экрана у ребёнка**.

**Состав killer feature:**
1. Три режима на входе: **«Нет сил»** · **«5 минут»** · **«Вместо мультика»**
2. **«Сказка сегодняшнего дня»** — одна фраза о дне → история
3. **12 «быстрых спасений»** — ситуации без промпта (перевозбуждён, двое детей, опаздываем…)
4. **Sleep-onset** структура по умолчанию (засыпание в финале)
5. **2 вопроса после сказки** + фраза для близости

### Value moment

**Момент:** уставший родитель в 21:00–22:00 за ≤60 сек получает готовый сценарий и думает:  
*«Я без сил, но у нас получился хороший вечер».*

**Эталонный сценарий:** голосовое «Маша поссорилась в садике, любит единорогов» → сказка 3–5 мин → вопросы → объятие.

## 4. Целевая аудитория

### Primary (MVP)

| | |
|--|--|
| **Персона** | «Уставший профи» |
| **Демография** | 28–42 года, РФ/СНГ, город |
| **Семья** | 1–2 ребёнка **2–7 лет**, часто двое работающих |
| **Контекст** | 18:00–21:30 — ужин, быт, укладывание; **время есть, энергии нет** |
| **Поведение** | YouTube/аудио, 3–4 книги по кругу, иногда ChatGPT |
| **Страх** | «Я плохой родитель, который не успевает» |
| **WTP** | 299–499 ₽/мес; разово 99–149 ₽ |

### Secondary (v1.1)

- **«Виноватый реалист»** (P4) — YouTube перед сном → сообщение «так же легко, без экрана»
- **«Вовлечённый кастомайзер»** (P2) — нишевые интересы, макс. WTP за персонализацию

### Не ЦА на старте

Родители, довольные только Алисой/Хрумом без контакта; B2B HR; продукт «только укладывание» без сказки.

## 5. Позиционирование

### Говорим

- «Помогает провести **тёплый ритуал перед сном**, даже когда нет сил»
- «**Персональная сказка на сегодня** — за 30 секунд»
- «**Быстрее YouTube** — без вины за экран»

### Не говорим

- «Бот читает вместо вас»
- «1000 сказок в библиотеке»
- «Уникальные ИИ-истории» (без привязки к вечеру)

---

## 6. MVP (scope)

### Включено (P0)

- `/start` + 3 кнопки режима энергии
- Генерация текста ≤30 сек
- Мини-профиль: имя, возраст, «без страшного», любимый герой
- Одна фраза / голосовое «что было сегодня»
- Safety-фильтр + sleep-onset шаблон
- Feedback после сказки
- Freemium: **5 сказок/нед**

### Включено (P1, первые 4 недели после пилота)

- 12 кнопок «быстрое спасение»
- Аудио TTS + «сделать спокойнее»
- Подписка (Telegram Stars / Prodamus)
- Push 20:30 (опционально)

### Вне scope MVP

- Voice cloning «бабушки»
- Mini App, B2B, 21-дневный ритуал, иллюстрации

## 7. Монетизация

| Тариф | Условия |
|-------|---------|
| **Free** | 5 сказок/нед, базовый профиль |
| **Подписка** | 299–499 ₽/мес — безлимит, персонализация дня, аудио |
| **Разово** | 99–149 ₽ — 3 премиум-сказки (тест WTP) |

**Платный слой:** имя + интересы + «сегодняшний день» + аудио без экрана.

---

## 8. Конкуренты и отстройка

| Конкурент | Их сила | Наша отстройка |
|-----------|---------|----------------|
| YouTube / Алиса | Нулевые усилия | Быстрее + **персонально на сегодня** + контакт родителя |
| BedtimeStory.ai, Talery | AI + персонализация | **Режим усталости**, Telegram, ритуал не каталог |
| Moshi, Storybook | Доказанный sleep | **Ваш ребёнок и ваш вечер**, не generic контент |
| ChatGPT | Гибкость | Zero prompt, детский safety, sleep-структура |

---

## 9. Метрики успеха (пилот)

| Метрика | Цель (4–6 нед) |
|---------|----------------|
| Time-to-story | < 60 сек (p90) |
| D7 retention (20:00–22:00) | ≥ 25% |
| «Уснул» / «спокойнее» | > 50% feedback |
| Конверсия free → paid | ≥ 3% (гипотеза) |
| NPS пилота | ≥ 40 |

**Главная гипотеза:** родители **регулярно** возвращаются, если ценность **быстрее YouTube** и сохраняет «я хороший родитель».

---

## 10. Риски (топ-3)

1. **Воспринимают как замену родителя** → копирайт «для чтения вам», не «включить няню»
2. **Не платят за generic сказки** → paywall на персонализацию дня
3. **Срыв укладывания из-за контента** → жёсткий safety + sleep-onset
