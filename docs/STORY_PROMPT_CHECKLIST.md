# Чеклист промпта сказки (сказкотерапия + Пропп)

**Для:** генерация LLM в боте «Сказка на ночь»  
**Источники:** Зинкевич-Евстигнеева («Практикум», «Основы», «Сказка в игре»), Строгова, Шорохова («Играем в сказку»), Ткач («Сказкотерапия детских проблем»), Пропп (морфология, адаптация).

**Не позиционировать как терапию** — чеклист улучшает качество семейного ритуала перед сном.

---

## 1. Вход (до генерации)

| # | Проверка | Где в боте |
|---|----------|------------|
| 1 | Есть имя ребёнка или осознанный дефолт «малыш» | профиль / `profile_or_default` |
| 2 | Возраст 2–7 влияет на длину и лексику | `word_target_for`, `_age_lexicon` |
| 3 | Режим энергии выбран (tired / medium / screen_free / today) | кнопки меню |
| 4 | `day_context` ≤ 500 символов, без мата и jailbreak | `DAY_CONTEXT_MAX` |
| 5 | `no_scary=true` → расширенный запрет образов | `story_safety.no_scary_rules` |

---

## 2. Морфология Проппа → сонная сказка

Полная схема Проппа не используется. Для 2–7 лет — **7 мягких функций**:

| Шаг | Пропп (идея) | В нашем промпте | % текста |
|-----|--------------|-----------------|----------|
| 1 | Исходная ситуация | Дом, комната, {hero}, вечер | ~10% |
| 2 | Недостача / зов | Усталость или событие дня **в метафоре** | ~25% |
| 3 | Отлучка | Тропинка, луч, порог в «страну снов» — **не опасно** | часть §2 |
| 4 | Даритель | Звезда, луна, родитель, зверёк → «дар покоя» | ~20% |
| 5 | Испытание | «Уложить» чувство, не победить врага | часть §2–3 |
| 6 | Возвращение | Снова кровать/дом, всё на месте | ~30% |
| 7 | Награда (свадьба) | **Покой и сон** вместо праздника | ~15% |

**Запрещено из классической морфологии:** злодей, похититель, битва, погоня, нерешённый конфликт.

Код: `bot/story_craft.py` → `PROPP_SLEEP_ARC`

## 3. Метафоры по возрастам

Выбрать **1–2** на сказку, не смешивать все сразу.

### 2–3 года (конкретные, телесные)

- [ ] плед / укрытие  
- [ ] ночник-звёздочка  
- [ ] зайчик или медведь, которого укладывают  
- [ ] «ш-ш-ш» ветра  
- [ ] тёплое облачко внутри  
- [ ] лодочка, покачивание  

### 4–5 лет (предметные символы)

- [ ] облачко дня на ладони  
- [ ] камушек-волнение → гладкий  
- [ ] фонарик на тропинке  
- [ ] мостик через ручей  
- [ ] гнёздышко / домик  
- [ ] семечко отдыхает  
- [ ] ниточка «мама/пapa рядом»  

### 6–7 лет (путь, образы)

- [ ] карта в страну снов  
- [ ] ключик от двери с тихим светом  
- [ ] островок тишины  
- [ ] зеркало, где день стал мягче  
- [ ] библиотека снов  
- [ ] рюкзак дня на крючке  
- [ ] маяк «домой»  

Код: `bot/story_craft.py` → `METAPHORS_BY_AGE`

## 4. Принципы сказкотерапии (в промпт)

| Принцип | Источник | В промпте |
|---------|----------|-----------|
| Безопасная дистанция — проблема в метафоре | Зинкевич, Строгова | `day_metaphor_map` |
| Герой ≈ ребёнок, идентификация | Практикум, Ткач | user: «герой — {name} или {hero}» |
| Экстернализация чувства (не «ты злишься», а «облачко») | Основы, Строгова | `DAY_METAPHOR_MAP` |
| Помощник рядом — не один | Практикум | шаг 4 Проппа |
| Без морали и стыда | все авторы | system + safety |
| Повтор / ритм — колыбельный эффект | Сказка в игре | «1–2 повтора образа» |
| Сенсорность: тепло, мягкость, звук | Играем в сказку | `skazko_principles` |
| Вопросы только после сказки | все | блок AFTER_STORY в боте |
| Тип: успокаивающая / с дугой / визуальная | Практикум | `MODE_INSTRUCTIONS` |

Код: `bot/story_craft.py` → `SKAZKO_PRINCIPLES`, `DAY_METAPHOR_MAP`

## 5. Перевод событий дня → метафора

| Событие дня | Метафора |
|-------------|----------|
| ссора, обида | взъерошенное облачко → разгладили |
| усталость, каприз | солнышко-батарейка село → зарядили объятием |
| страх, тревога | камушек в кармане → стал гладким |
| не хочет спать | зайчик ищет мягкую подушку |
| садик, новое | новая тропинка + фонарик-проводник |
| много впечатлений | полный рюкзак → повесили у двери сна |

## 6. QA после генерации (автомат + ручной)

### Автомат (`story_safety.check_story`)

- [x] нет слов из чёрного списка (страшное, насилие)  
- [x] нет `?` в последних 200 символах  
- [x] проверка ИИ-штампов (`check_ai_cliches`)  
- [x] режим today: нет дословной цитаты `day_context` (`check_today_verbatim`)  
- [x] при fail — retry strict → fallback  
- [x] автотесты: `bot/tests/run_all.py` (6 модулей)

### Ручной (матрица 18 кейсов)

См. **[STORY_QA_RELEASE.md](./STORY_QA_RELEASE.md)** §2.

- [ ] пройдены все 7 шагов Проппа (хотя бы намёком)  
- [ ] 1 метафора возраста (не каталог)  
- [ ] финал — сон, не конфликт  
- [ ] имя ребёнка 3–5 раз  
- [ ] укладывается в Telegram (≤4096 с footer)  
- [ ] родитель может прочитать вслух за целевое время
