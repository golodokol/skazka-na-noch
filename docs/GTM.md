# Go-to-market

---

## 1. Позиционирование (коротко)

**Для** работающих родителей детей 2–7 лет,  
**которые** вечером не имеют сил придумывать сказку,  
**«Сказка на ночь»** — Telegram-бот,  
**который** за 30 секунд даёт персональную сонную историю для чтения вслух,  
**в отличие от** YouTube и ChatGPT,  
**потому что** быстрее, безопаснее для сна и сохраняет ваш контакт с ребёнком.

---

## 2. Ключевые сообщения

| Канал | Hook |
|-------|------|
| TG пост | «Ребёнок просит сказку, а в голове пусто? Одна кнопка — 30 сек — читаете сами» |
| Reels | Screen record: фраза о дне → сказка → «уснул» |
| Чат мам | «Не заменяет вас — подсказывает что рассказать» |

---

## 3. Каналы (приоритет)

| # | Канал | Действие |
|---|-------|----------|
| 1 | Родительские Telegram-каналы | Нативный пост / бартер |
| 2 | Личная сеть | 30 пилотных семей |
| 3 | TikTok / Reels | 3 ролика «сказка из одной фразы» |
| 4 | Детские психологи / педиатры | Партнёрство «проверено» (v2) |
| 5 | Кросс-промо (беременность/новорождённые) | v2 |

---

## 4. Launch plan (2 недели)

### Неделя −1 (pre-launch)

- [ ] BotFather: имя, аватар, описание
- [ ] 10 альфа-тестеров (закрытая ссылка)
- [ ] Landing: t.me/bot + 3 bullet value prop
- [ ] Подготовить 2 поста для каналов

### Неделя 0 (launch)

- День 1: альфа → фиксы
- День 3: пост в 1 канале (5–20k подписчиков)
- День 5: сбор первых отзывов (скрины)
- День 7: второй канал + рефералка

### Неделя 1–4 (пилот)

- Еженедельный опрос
- Итерация промптов по feedback
- Включение paywall (неделя 3)

## 5. Креативы (черновики)

**Пост A (боль):**

```
21:30. Ужин, ванна, «мама, сказку!» — а в голове пусто.

Сказка на ночь в Telegram: одна кнопка → персональная сонная история за 30 секунд.
Читаете вы. Бот только снимает «что придумать».

5 сказок в неделю бесплатно → @YourBot
```

**Пост B (демо):**

```
Ввели: «Сегодня Лёва строил башню и не хочет спать»
Получили: [скрин 3 абзацев]
Через 5 минут — «уснул» ✅
```
