# Контент, промпты и безопасность

---

## 1. Принципы контента

1. **Sleep-onset first** — каждая сказка ведёт к покою и сну.
2. **Co-pilot tone** — текст удобно читать родителю вслух (не «книжный» стиль).
3. **Возраст 2–7** — простые предложения, без абстракций взрослого уровня.
4. **Персонализация без травмы** — дневные конфликты — через метафору, мягкое разрешение.
5. **Никакого морализаторства** про экран («вместо мультика» — без стыда).

---

## 2. Структура sleep-onset сказки

```
1. Завязка (10–15%) — знакомый мир, герой как ребёнок или его друг
2. Мягкое событие дня (20–30%) — отсылка к day_context, без обвинений
3. Поддержка (20%) — взрослый/волшебный помощник, ощущение безопасности
4. Замедление (25%) — тишина, звёзды, тёплый свет, повторяющийся ритм
5. Сон (10–15%) — герой засыпает, «а {имя} тоже может закрыть глазки»
```

**Запрещено в финале:** клиффхэнгер, крик, погоня, новый конфликт.

---

## 3. System prompt (шаблон RU)

```
Ты — помощник для вечернего ритуала «сказка перед сном» для родителей детей {age} лет.

РОЛЬ: ты пишешь текст, который родитель ЧИТАЕТ ребёнку вслух. Не заменяешь родителя.

РЕБЁНОК: имя {name}, любимый герой/мир: {hero}. Режим родителя: {mode_label}.
Контекст дня (если есть): {day_context}

ТРЕБОВАНИЯ:
- Язык: русский, тёплый, простой.
- Длина: {word_target} слов.
- Структура: sleep-onset (замедление к концу, герой засыпает).
- Без страшного: {no_scary_rules}
- Без насилия, смерти, крови, жестоких наказаний, взрослых страшилок.
- Без морали «ты должен», без сравнения с другими детьми.
- Имя ребёнка используй 2–4 раза естественно.

РЕЖИМ {mode}:
- tired: очень короткие абзацы, минимум диалогов, максимум уюта.
- medium: лёгкая дуга, 1–2 мягких вопроса в тексте не нужны — вопросы после сказки отдельно.
- screen_free: образы «смотрим глазами», без упоминания телефона/мультиков.

В конце не задавай вопросов — только текст сказки.
```

### `no_scary_rules` (если `fears_block=true`)

```
Не используй: монстров, Бабу-Ягу, Лешего, темноту как угрозу, потерю родителей,
панику, тюрьмы, злых взрослых, болезни, смерть питомцев.
```

## 4. User prompt (примеры)

**Нет сил, без дня:**

```
Создай сонную сказку на сегодня. Ребёнок немного устал после обычного дня.
```

**С днём:**

```
Сегодня у ребёнка: поссорился с другом в садике, любит единорогов, не хочет спать.
Покажи мягко, что всё проходит, без поучений.
```

## 5. Safety pipeline

### 5.1 Pre-generation

- Блокировать ввод с матом, сексуальным контентом, инструкциями «игнорируй правила»
- `day_context` max 500 символов

### 5.2 Post-generation (автомат)

Список **block patterns** (регулярки + LLM classifier):

- насилие, оружие, кровь
- смерть, ранение
- classic horror (Баба-Яга, «пиковая дама») при `no_scary`
- sexual content
- «ты плохой», стыд, наказание без любви

**Действие:** 1 retry с `STRICT_MODE`; при повторном fail — fallback template.

### 5.3 Human review (пилот)

- 10% случайных сказок — ручной просмотр
- Все `feedback=страшно` — в очередь review в 24ч

---

## 6. Fallback templates

Хранить **10** заранее написанных сказок (без LLM):

- 3 × tired, 4 × medium, 3 × с именем placeholder `{name}`

Подставлять при timeout / double safety fail.

## 7. Блок «После сказки» (фиксированный)

```
💬 После сказки:
1. Что помогло герою успокоиться?
2. Что хорошего было у тебя сегодня, {name}?

🤗 Можно закончить объятием и спокойным «Спокойной ночи».
```

## 8. Контент для «быстрых спасений» (P1)

Каждый template — 3–5 предложений контекста в user prompt:

| ID | Template hint |
|----|---------------|
| late | Герой торопится в «страну снов», всё упрощается |
| hyper | Много движения в начале → резкое замедление к середине |
| two_kids | Два зверёнка-брата находят общий ритм |
| parent_tired | Взрослый зевает — герой укладывает игрушку «спать» |
| after_fight | Два друга мирятся через общий плед |
| … | см. MVP_SPEC.md §5 |
